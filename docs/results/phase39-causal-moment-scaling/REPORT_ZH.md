# Phase 39 因果前缀矩率缩放验证筛选

## 方法

保持 Phase 39 的网络结构、参数量和 `L_synth=0.5` 不变。训练时为每个原始样本配对一个物理一致样本：采样
`delta_Mw in [-0.75, 0.5]`，将径向波形、模型输入和 STF 同乘
`10^(1.5 * delta_Mw)`，同时将监督震级改为 `Mw + delta_Mw`。距离、方位、到时和有效掩码不变。

该方法没有新增网络层、adapter、teacher、循环状态或手工 PGD 特征。合成波形损失同时约束原始样本和缩放样本。

三次冻结配置运行的新方法均值为 `0.13979 +/- 0.01930 Mw`，对应 Phase 39 基线均值为 `0.22993 Mw`，平均改善 `0.09014 Mw`。三次均低于 0.20 和 0.17。

fold 0 中，主要改进来自低震级 Parkfield2004；两颗种子都将其误差从约 0.84-0.96 降到约 0.29-0.32 Mw。Noto2024 有所退化，因此后续正式 OOF 仍需检查逐事件一致性，不能只报告平均值。

## 边界

以上都是内部验证事件结果，不是测试折结果，也不是 8 个外部未见事件结果。本轮没有读取或评分测试折和外部事件。

下一步应冻结当前配置，实施正式 5 折 OOF；在看到 OOF 结果后不再回头调本配置，避免测试泄漏。
