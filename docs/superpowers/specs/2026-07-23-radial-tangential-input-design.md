# R+T 水平双分量受控实验设计

**日期：** 2026-07-23  
**状态：** 对话设计已批准，待书面规格复核

## 目标

在不改变 USGS-priority 数据、台站样本、拆分、STF、损失权重、优化器或训练轮数的前提下，将模型输入从单径向分量 R 改为径向和切向双分量 R+T，隔离检验切向信息是否改善走滑型和低震级事件的震级估计。

首轮只训练 seed 42。该轮通过预定门槛后，再单独决定是否训练 seeds 17/73；本规格不自动授权三种子正式训练。

## 已选方案与替代方案

已选方案 A：继续以径向峰值 `R > 2 cm` 筛选训练样本，只增加 T 输入通道。这保证与 R-only 基线尽可能严格同行比较。

本轮不采用：

- `max(R,T) > 2 cm` 筛选：会同时改变样本集，无法将改善归因于 T 通道。
- R+T+Z 三分量：会混入用户判断信噪比较低的 Z，无法单独评估 T。
- 切向物理正演损失：需要新的 SH/切向辐射公式，会增加未验证的科学变量。

## 数据合约

对每个台站，使用现有震源到台站方位角 `A` 将 E/N 旋转为：

```text
R = E * sin(A) + N * cos(A)
T = E * cos(A) - N * sin(A)
```

T 使用与 R 相同的单位换算、基线校正、低通滤波、1 Hz 重采样、200 秒窗口和有效率校验。旋转后应在浮点容差内满足水平能量不变式 `E^2 + N^2 = R^2 + T^2`。

为保证样本集不变，R 通过现有接受条件后，若 T 无法以同一时间轴和有效性要求生成，数据构建必须整体失败并报出 event/station，不得静默删除该台站。

样本接受与拒绝仍只由现有 R 路径决定。R+T 数据审计必须确认：

- accepted event/station 集合与当前基线完全一致；
- 仍为 31 个事件、2483 个台站样本；
- seed-42 的 train/validation/test 记录与 split hash 不变；
- R 数值与现有基线逐样本一致，T 全部有限。

## 模型与数据流

配置显式声明波形输入分量。旧配置缺省时等价于 `radial`，R+T 实验显式选择 `radial,tangential`。模型的首个 `Conv1d` 输入通道数由该配置确定，其余 TCN、SE、Transformer、STF head 和 catalog-Mw head 不变。

训练、内部评估和外部事件评估必须通过同一个组装入口按配置生成 `(batch, channels, time)` 输入，防止训练/推理通道顺序不一致。径向张量继续单独保留给现有物理损失。

旧 R-only 配置和 checkpoint 必须继续严格加载。R-only 与 R+T checkpoint 形状不同，错用配置时必须立即报出明确的通道不匹配错误，不允许部分或非严格加载。

## 物理损失边界

当前的合成波形损失继续仅使用 R 观测量，并继续使用当前 `phi_slip` 辐射花样。T 只参与网络特征编码，不新增 T 合成位移损失。

该边界保证首轮实验只回答一个问题：在其他条件不变时，向网络提供 T 是否改善震级估计。

## 验证与 seed-42 门控

实现按 TDD 进行，至少覆盖：

1. E/N 到 R/T 旋转、符号和水平能量不变性；
2. T 与 R 的预处理一致性和有限性；
3. R-only 默认行为与旧 checkpoint 严格加载；
4. R+T 在训练、内部评估和外部评估的通道顺序一致；
5. R+T 前向、损失、梯度和 CPU/CUDA finite smoke；
6. accepted rows 与 split 不变审计，并为新 R+T 输入独立记录哈希。

聚焦测试、完整回归和 GPU smoke 通过后，使用与基线相同的 seed-42 split 训练 200 epochs。仍使用 `station_mae_catalog` 选择 checkpoint，以避免同时修改模型选择目标。

门控为：

- station MAE `<= 0.0885`（基线 `0.0835` + `0.005`）；
- event MAE `<= 0.1613`（基线 `0.1513` + `0.010`）；
- 走滑型 event MAE `< 0.1801`（必须优于同 seed R-only 基线）。

同时报告低震级走滑事件 MAE，但不另设第四个门槛，避免小样本过度门控。任一强制门槛失败则停止，保留运行证据，不自动训练另外两个种子。

## 外部事件边界

固定 8 个外部事件仅在 seed-42 内部训练和门控结束后评估一次。外部指标不选 checkpoint、不改门槛、不触发调参。

报告总体 station/event MAE，以及走滑、正断层、逆冲分层结果；泸定作为已知诊断事件单独报告，但不作为训练成功门槛。

## 产物和失败行为

代码修改、配置、测试、seed-42 checkpoint、split、日志、预测 CSV、机制分层汇总和输入哈希必须使用新提交与唯一运行目录。当前 USGS 快照、R-only 运行、旧 GCMT 数据和所有旧 checkpoint 保持只读。

任一非有限值、样本集变化、split 变化、严格 checkpoint 加载失败或输入通道不一致都必须立即停止。失败不覆盖或删除任何基线产物。
